## Technical Details

### What Changed in Step 7.9
**Before** (Bug):
```bash
3dClust -1Dformat -nosum -1noneg -dxyz=1 -prefix ${out} ${clust_thresh} 1 ...
# Output: Text report only, no .nii.gz file
```

**After** (Fixed):
```bash
3dClust -nosum -1noneg -dxyz=1 -prefix ${out_tmp} ${clust_thresh} 1 ...
if [ -f "${out_tmp}+orig.HEAD" ]; then
    3dcopy ${out_tmp}+orig ${out}
    rm -f ${out_tmp}+orig.*
fi
# Output: Proper 3D volume in NIfTI format
```
